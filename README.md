# Raccoon With a Mortgage

One-line roast of a smart fridge that refuses to open after midnight, for make.fun's **Midnight Fridge Roast** bounty ($2 in USDC).

The fridge locks at midnight, so the owner eats standing in the dark — and the punchline is the self-image at the end: a raccoon with a mortgage. Petty rule, grown-up stakes, an animal sneaking around its own kitchen.

> My fridge locks at midnight, so I eat standing in the dark like a raccoon with a mortgage.

## Run it

```sh
node main.ts
```

This writes the line to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exactly 90 characters, no trailing newline.
